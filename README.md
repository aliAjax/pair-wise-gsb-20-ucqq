# hxwl-06 显微镜玻片观察

九宫格视野观察记录台：在 3×3 格位上逐格登记重点结构，提交后可回看、筛选。

## 技术栈

React + Vite + TypeScript + CSS（纯前端，本机保存）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5106

## 功能

- **九宫格登记**：选定样本与倍率后，点格子登记细胞壁、细胞核或纤毛；同一格只保留一种判断（再点替换或取消）
- **格位状态**：每格为「某结构 / 与视野无关 / 未判断」之一，无关格位保留在本页提示，不计入结构判断
- **倍率沿用**：切换倍率不清空标注，九格判断按原位置沿用（标注按样本维度保存）
- **样本隔离**：登记工具由样本大类决定（血液涂片只允许细胞核，不会混进细胞壁 / 纤毛等植物、微生物结构）
- **本页提示**：重点结构为空时阻止提交并在页面内说明；存在无关格位或未判格位时给出非阻断提示
- **记录筛选**：提交后按样本、倍率、结构三个维度组合筛选，迷你九宫格回看位置
- **现场恢复**：样本、倍率、各样本九格标注和备注实时写入 localStorage，关掉页面再打开自动找回

## 代码组织（三层分离）

```
src/
├── data/          # 观察资料层：领域类型、样本/倍率/结构目录、预置数据
│   ├── types.ts
│   └── catalog.ts
├── rules/         # 判断规则层：结构适用性、同格单选、提交检查、筛选（纯函数）
│   └── judgment.ts
├── storage/       # 本机保存层：localStorage 读写、版本命名空间、数据消毒容错
│   └── local.ts
├── components/    # UI 组件：九宫格、工具盘、记录列表
└── App.tsx        # 页面装配与状态
```
