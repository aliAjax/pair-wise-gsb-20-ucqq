# hxwl-06 显微镜九宫格观察记录

把显微观察结论登记到 3×3 视野格位中，老师回看时可定位问题出现在视野的哪个位置。

## 技术栈

React 19 + Vite + TypeScript + CSS（无额外运行时依赖）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5106

## 使用流程

1. **选定样本与倍率**：洋葱表皮（植物组织）、人血涂片（血液涂片）、草履虫（微生物）、人口腔上皮细胞（动物组织），倍率 100× / 400× / 1000×。
2. **点格登记**：先选「细胞壁 / 细胞核 / 纤毛」再点九宫格。同一格只能保留一种判断（换结构覆盖、再点同一种撤销），橡皮擦可清除。
3. **倍率沿用**：倍率变化时标注按格位保留——100× 覆盖 9 格、400× 中心十字 5 格、1000× 中心 1 格；视野外的格位斜纹标注，只提示不丢弃。
4. **样本隔离**：每个样本的格子分别保存，血液涂片的标注不会混进植物组织；不适用的结构按钮自动禁用。
5. **本页提示**：重点结构为空、或格位与当前视野无关时，提交会被拦下，错误/警告提示留在本页并给出切倍率或擦除的引导。
6. **提交与筛选**：提交后可按样本、倍率、重点结构三个维度筛选记录。
7. **草稿找回**：样本、倍率、格子自动保存到本机 localStorage，关掉页面再打开可继续；本机保存与观察资料、判断规则分开组织。

## 代码分层

```
src/
├── data/observation.ts        # 观察资料：样本、结构、倍率视野格位（不含规则与存储）
├── rules/observationRules.ts  # 判断规则：结构适用、同格单一判断、视野沿用、提交审查
├── storage/localStore.ts      # 本机保存：草稿 / 记录的 localStorage 读写与容错
├── components/                # 界面组件
│   ├── ControlPanel.tsx       # 样本、倍率、登记工具
│   ├── GridBoard.tsx          # 九宫格、本页提示、提交
│   ├── RecordsPanel.tsx       # 提交记录与三维筛选
│   └── MiniGrid.tsx           # 记录卡片的九宫格预览
└── App.tsx                    # 组装三层与页面状态
```
